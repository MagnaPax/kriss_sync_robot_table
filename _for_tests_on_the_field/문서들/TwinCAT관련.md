# TwinCAT 로그인

---

### 1. 타겟 시스템(Target System) 확인

먼저 코드를 넣을 대상(PC 자기 자신 혹은 외부 Beckhoff 장비)이 올바르게 선택되어 있는지 확인해야 합니다.

* 상단 툴바의 **Choose Target System** 드롭다운 메뉴(보통 `<Local>` 또는 장비 이름이 써 있음)를 확인합니다.
* 장비와 연결이 안 되어 있다면 `Choose Target System...`을 눌러 연결할 장비를 선택하세요.

### 2. 구성 활성화 (Activate Configuration)

PLC에 로그인하기 전, 현재 설정된 하드웨어 구성(I/O, 드라이브 등)을 먼저 컨트롤러에 심어줘야 합니다.

* 상단 메뉴 아이콘 중 **파란색 회전 화살표 모양(Activate Configuration)** 버튼을 클릭합니다.
* "기존 구성을 덮어쓰겠습니까?"라는 창이 뜨면 **OK**를 누릅니다.
* "TwinCAT을 Run Mode로 재시작하겠습니까?"라는 창이 뜨면 **OK**를 누릅니다. (이때 시스템 트레이의 TwinCAT 아이콘이 파란색에서 **초록색**으로 변해야 합니다.)

### 3. PLC 로그인 (Login)

이제 작성한 로직을 PLC 메모리에 올릴 차례입니다.

* **방법 A:** 상단 메뉴에서 `PLC` -> `Login`을 클릭합니다.
* **방법 B:** 툴바에서 **키 모양(Login)** 아이콘을 클릭합니다.
* **방법 C:** 단축키 `F11` (또는 프로젝트 설정에 따라 다름)을 누릅니다.

> [!IMPORTANT]
> **로그인 시 주의사항**
> * "The Application does not exist on the target... Create it?" 같은 메시지가 뜨면 **Yes**를 누르세요. 코드를 처음 넣을 때 나오는 정상적인 메시지입니다.
> * 로그인이 완료되면 코드 편집창의 변수 값 옆에 실시간 데이터가 표시되지만, 아직 프로그램이 '실행'된 것은 아닙니다.
> 
> 

### 4. 프로그램 시작 (Start)

로그인 직후에는 PLC가 'Stop' 상태일 수 있습니다.

* 상단 툴바의 **초록색 재생 버튼(Start)**을 누르거나 `F5`를 눌러 프로그램을 실행하세요.

---

**만약 "ID/Password"를 묻는 팝업이 뜬다면?**
보통의 경우 비밀번호가 설정되어 있지 않지만, 장비 보안 설정이 되어 있다면 기본값은 다음과 같습니다.

* **User:** `Administrator`
* **Password:** `1` (숫자 1)
